# 画后 · Afterframe

面向 AI 生成图像的视觉诊断与修整 Skill。结合图片、创作目标和可选参考，找出最影响目标的视觉机制，辅助局部修复或整体观感／画法调整，并通过前后对照复核结果。

画后从轮廓与形体、线条与边缘、明暗与色彩、材质与光泽、细节与主次中选择相关维度，将“油腻”“塑料感”“不清爽”等诉求落实为具体调整。支持混合风格，保留有意的夸张、梦境与拼贴，不套用统一的“去 AI 感”滤镜。

## 安装

将本仓库克隆到以下任一位置，或创建 `afterframe` 目录并复制 `SKILL.md`、`references/` 和 `agents/`，保持相对目录结构。`examples/` 仅供查看示例，无需安装：

- 项目内使用：`.agents/skills/afterframe/`
- 个人使用：`~/.agents/skills/afterframe/`

确保 `SKILL.md` 直接位于 `afterframe` 目录下。安装后若未出现，重启 Codex 后重试。详见 [Codex Skill 官方说明](https://learn.chatgpt.com/docs/build-skills)。

## 使用

附上图片，说明用途和希望保留的内容：

> 使用 $afterframe 检查这张人物插画，用于绘本封面。保留夸张的大眼睛和构图，先给出修整建议。

画后先说明最值得改的内容、预期收益和主要代价，再给少量有依据的建议。你可以选择其中几项处理，也可以直接指定修改范围：

> 只修整右下角非预期的模糊边缘，保留像素网格与配色，输出新文件。

也可以附上画法参考，明确允许变化的范围：

> 参考第二张图的明暗分组和边缘处理，调整第一张的画法。保留角色身份、发型轮廓、服装设计和构图，允许简化内部线条与碎阴影，直接输出新版本。

局部修复重点检查非目标区域的稳定性；画法调整允许约定范围内的渲染变化，同时单独检查角色与设计是否偏移。

## 说明

- 仅请求诊断时交付建议；已明确要求修改时，在授权范围内直接执行，不重复确认。默认另存新版本，前后对照检查目标效果、保护内容和副作用；未改善时说明原因、修正或回退。
- 编辑依赖宿主提供的工具；没有编辑工具或无法满足硬性保护要求时，明确说明未执行，并提供可行的操作方案。
- 生成式编辑可能改变细节，人物特征、文字和标识等需要复核。
- 不检测 AI 来源，不提供“AI 感百分比”，不处理去水印或来源伪装。
