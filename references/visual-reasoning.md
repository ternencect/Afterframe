# 观感与参考分析示例

在用户用观感词表达目标，或提供画法参考而需要拆解差异时阅读。以下是条件性示例，不是缺陷清单或统一处理配方。每次只选择实际图片支持、与用户诉求有关的机制。

## 从感受回到图像

| 诉求及图像证据 | 可选调整与验收 | 需要保护的差异 |
| --- | --- | --- |
| “塑料感”：头发或皮肤出现连续大亮面，边缘反差与密线进一步强调亮带 | 若目标更柔和，减少亮带面积或对比，重新组织过渡；检查体积与发束是否仍清楚 | 不连带消除金属、宝石和玻璃的必要亮点 |
| “太满”：焦点以外仍密布等强线条、装饰或碎阴影 | 降低非焦点区域的强调，合并重复信息；检查主体是否更易读 | 不默认删除构成角色辨识度的装饰，不把全图模糊当作简化 |
| “僵硬”：本应柔软的衣料或有动势的发束，其轮廓、内部线条呈重复等距转折 | 按目标调整疏密与转折节奏，检查动作和柔软感；先排除有意几何化设计 | 保留关键外形、服装结构和有意的图案秩序 |
| “脏／碎”：同一形体内的小块明暗切割妨碍大体积阅读 | 按受光与目标画法重组明暗块，检查缩小后是否更清楚 | 保留有叙事价值的纹理与真实污渍，不默认去色或磨皮 |
| “没有绘画感”：只有笼统感受，尚无明确画法证据 | 比较线条取舍、形体概括、明暗分组、边缘和细节层级；提出有依据的方向，必要时询问目标媒介或参考 | 不自动添加笔触、颗粒、纸纹，也不声称能证明人工来源 |

布褶亮白高光与陡峭暗部可能强化滑亮质感，但缎面、漆皮本就可能需要这种表达。要先判断目标材质或画法，再决定降低反差、改变高光形状，还是保留。相同现象可有不同解释。

## 从参考提取画法

将比较写成“原图现象 → 参考采用的组织方式 → 本次允许的变化 → 验收依据”，只提炼相关差异。例如：

- **平涂动漫参考**：原图头发内线和碎亮点密集，而参考用大束与少量阴影表达转折。可合并渲染细节，保留发型轮廓和关键发饰；验收看束状组织与明暗是否清楚，而非单纯高光变少。
- **绘画性软硬边参考**：原图各区域边缘同样清晰，而参考在焦点保持明确边缘、次要区域适度融合。可重新分配边缘强弱；验收看焦点与形体是否成立，不能全图模糊。
- **亮面材质参考**：参考依赖清晰反射与小面积强亮点。调整应考虑高光位置、形状及周围明暗关系，不能套用哑光化。

参考中的角色比例、配饰、姿态或背景变化不自动成为迁移目标。多张参考相互冲突时，优先采用用户指定的部分；若取舍决定整体方向且无法推断，再询问。不要擅自平均成一种风格。
