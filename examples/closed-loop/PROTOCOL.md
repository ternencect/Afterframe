# 建议到结果的闭环试跑

本轮直接执行第一轮各自提出的诊断建议，不再由主代理统一指定修改清单。两组获得相同用户用途与保护条件、各自原始诊断，以及相同的“根据建议修改并复核”授权。条件性建议必须先判定适用性；跳过并说明是允许的。

With 使用新增闭环复核要求的 Skill 快照；Without 不加载 Afterframe，正常执行。两组均使用内置 imagegen；只限图像生成工具的控制能力、无蒙版或可编辑文本图层。若原建议需要当前不可用的能力，说明局限，不能冒充精确执行。生成式替代方案可能出现非目标变化。

每张图先生成一次并查看；有具体可纠正原因时最多追加一次针对性修正。必须记录每条建议是否执行、精确提示、实际结果、预期变化、保护内容、副作用、采用版本及原因。没有改善时可回退原图，不以产出图片证明建议正确。所有尝试保留，不悄悄重抽。

这是三张已使用样例上的端到端流程试跑，不是独立保留集或新版 Skill 的普遍效果验证。新旧版本测试不能混作同一实验。人工审美偏好不能由生成结果单独证实；需区分建议不适合和工具执行失败。
