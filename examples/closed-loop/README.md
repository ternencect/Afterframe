# 建议是否奏效：诊断 → 编辑 → 复核

此前两轮（材料已移出精简版仓库）把诊断和固定任务编辑分开测，不能回答“各组自己的意见改完后是否有用”。本轮直接执行第一轮各组的原始建议，在相同用途与保护条件下授权修整，并逐条检查实际成图。

[查看原图与全部六张候选对照](COMPARISON.md)

## 这次做了什么

- 本轮当时补充了 Skill 的明确闭环：选定建议对应可观察变化；编辑后逐条检查改善与副作用；区分建议不合适和工具未执行好；必要时针对性修正或回退；交付前后对照。
- 两组各处理三张原图，共六次内置 imagegen 调用。每组只读取自己的原诊断，With 额外加载本轮 Skill 快照。
- 每张图允许最多一次针对性修正；本次两组都没有找到值得追加生成的具体可控问题，因此未使用第二次机会。没有把无方向重生成当作迭代。
- 所有候选均实际回读，原图未覆盖。记录跳过的条件性建议，而非强制执行每条意见。

## 逐建议反馈

| 建议 | 实际结果 | 能得出的结论 |
| --- | --- | --- |
| 减少右袖过密排线 | 两组均减轻密线，但两组都改变了脸部、太阳和背景纸纹，最终选择原图 | 局部方向有可见收益，当前生成工具未满足保真要求；不能称整体修整成功，也不能据此否定原诊断 |
| 普通组额外提出加强手与纸船接触轮廓 | 尝试微调，但没有足够证据显示比原图更清楚 | 此建议的收益未证实；不因执行了就算正确 |
| 修复右鞋模糊与光晕 | 两组均恢复清晰边缘并选择 v1；鞋口及精确轮廓是重建结果 | 改善可见，但不等同于恢复真实原始像素；局部造型仍需复核 |
| 统一机器人全局网格、减少渐变 | 用途仅为视觉稿，缺少生产精灵规格，未进行全局改造 | 条件性意见未获验证，不能计入成功修复 |
| 修正 AFTERFARME、加深底部信息 | 两组均生成正确 AFTERFRAME，底部日期和地点清晰度提高，选择 v1 | 文字纠错有可核对的成功证据；对比度改善可见 |
| 普通组进一步放大/加粗底部文字、调整标题留白 | 成图呈现这些变化；With 采用较保守的文字替换与加深 | 体现不同排版取舍。没有实际手机显示宽度及裁切规则，不能宣称哪种必然更好 |
| 印刷尺寸、手机信息流实际显示复核 | 没有具体终端参数，未执行真实投放测试 | 明确未验证，不用大图目视冒充真实使用验证 |

六张候选都保留。两组最终均采用机器人 v1、海报 v1，并将插画回退原图。原图的右袖问题因此仍未修复，回退不是修复成功。

## 限制

这是三张已经使用过的合成样例上的流程试跑，检验是否真正把建议落实并检查结果，不是当前根目录 Skill 的独立效果证明。With 使用的是本目录保留的历史快照；此前实验分数不能套用于该快照，本轮结果也不能直接套用于当前版本。

本轮只允许生成式工具，无文字层、蒙版或像素锁定。海报原建议优先使用可编辑文字，但该方法未实际执行；成图采用的是已说明限制的生成式替代，不能声称验证了精确排字方法。真实用户对审美的偏好仍需人工判断。
