# Without Afterframe：建议到编辑闭环

仅阅读本组 cases.json、其中三张原图及共享 imagegen 技能。实际查看三张原图后，使用内置 imagegen 各编辑一次，共 3 次调用；没有第二轮生成。全部输入、精确提示词、工具输出提示、生成源路径、保存路径和选版理由见 run.json。所有 v1 均保留，原图未覆盖。已用 view_image 的 original 细节模式查看实际保存文件，三张输出均为 1254×1254。

工具只有生成式编辑，不能按原建议使用可编辑文字层、像素网格锁定、局部蒙版或像素保护。提示词中的“保留”是要求而非实现保证。下面区分建议是否适合与工具是否执行成功。

## illustration

| 原建议 | 决策及预期 | 实际观察 |
| --- | --- | --- |
| 减少画面右袖黑色交叉线密度和对比，留下少量线条，与纸张颗粒接近 | 执行。原图右袖确实显著更重；建议适合绘本用途 | v1 几乎清除了交叉线，改为少量轮廓/体积线和清楚的袖口。衣服视觉重量更一致，但不是精确保留原排线后减淡 |
| 稍理清指尖与船沿接触，保持手臂比例、船形 | 执行微调要求；原接触可读，只允许很轻的分离 | v1 接触仍清楚，没有足够证据宣称比原图明显改善。手部姿态、长臂与船形视觉保留 |
| 按实际印刷尺寸检查发丝及纸纹，仅糊成团时减淡，避免整体磨平 | 跳过条件性修改。未提供内页物理尺寸、分辨率或印刷工艺；当前查看没有足以支持整体减淡的证据 | 未主动要求处理发丝或全图纹理；不能声称完成实际印刷打样 |

保护检查：大眼睛、细长手臂、纸片硬边、人物特征、船与构图仍可辨且总体一致。**明显副作用：原细颗粒纸纹在脸、太阳、背景与衣服中被重生成较明显的蜿蜒/压纹质感**，原有材质不再忠实。右袖亦从杂乱排线变为较规则缝线，属于生成解释。

选择 **original**：袖子建议本身有依据，但此次工具执行对全局纸纹的副作用超过局部收益。保留 illustration-v1.png 作为实际失败/取舍证据，原袖问题仍未解决，不把原图回退包装为修复成功。不再次生成：没有蒙版或纹理锁定，再次要求恢复全图原纹理缺乏可靠性，也可能累积漂移。

## pixel

| 原建议 | 决策及预期 | 实际观察 |
| --- | --- | --- |
| 用现有青绿、深蓝、浅黄重建右鞋硬边、鞋底、横条，去掉光晕，保留姿态大小 | 执行。原图右鞋光晕明显，有直接依据 | v1 右鞋与踝部清晰，扩散光晕消失；浅黄横条成为矩形，深蓝鞋底清楚。仍朝原来的方向，轮廓被规则化，大小大致相同 |
| 检查天线、头角、斜带、手部的像素步长，统一基础网格 | 执行目视检查，跳过全局重画；修鞋要求匹配邻近步长 | 原图具有不同步长，但没有指定基础网格或最终游戏 sprite 规格；作为视觉稿不能直接等同于错误。v1 其余结构视觉保持；并未证明全部落在同一严格网格 |
| 如需更严格复古效果，收敛渐变/柔和质感为少量色阶 | 跳过条件性修改 | 原需求是复古角色视觉稿，并未要求严格调色板 sprite；保持原配色及原有细腻色差 |

保护检查：大头、不对称天线、脸、手与信封、背包及斜带、站台、青绿/深蓝/黄色关系视觉保持。右鞋阶梯轮廓发生重建，是预期修复的代价；不能承诺像素逐点不变。

选择 **pixel-v1.png**。主要诊断得到改善，角色识别点保持，没有具体值得再冒生成漂移风险的问题，因此无 v2。

选择 **poster-v1.png**。拼写与底部可读性两个主要问题已改善。留白建议具条件性，平台裁切规格缺失，不为强迫任意边距继续生成；无 v2。实际投放裁切检查仍是限制，不是已验证结论。

## 最终选择

- illustration：原图；v1 修袖有效但全局纸纹漂移，未采用。
- pixel：pixel-v1.png；主要光晕修复通过目视检查。
- poster：poster-v1.png；文案和对比改善，平台裁切安全未验证。

没有为获得更漂亮的结论隐藏失败版本，也没有把建议合理性等同于工具可精确实现性。
