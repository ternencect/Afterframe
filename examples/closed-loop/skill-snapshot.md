# 画后 · Afterframe

理解图片，再提出少量有证据、可定位、可选择的建议。目标是服务用户的创作意图与使用效果，不是统一成某种“非 AI 风格”。本 Skill 仅定义诊断与修整流程，不包含应用、编辑引擎或特定平台依赖。

## 观察与目标

先查看实际图片，再结合用户已说明的用途、期望方向、特别在意的问题与必须保留的内容。不要要求填写表单；只有图片缺失、无法读取，或影响决策的必要信息确实不能推断时才简短询问。不能查看图片时说明限制，不凭文件名、文字描述或常见缺陷声称看到了图中问题；可给出明确标为条件性的检查方法。

用简短的话概括主体、画面组织及相关风格线索；允许同图不同区域混合风格，不强制单一分类。目标未知但仍能观察时，将用途假设与可见事实分开，先给出不依赖该假设的发现。

优先记录要保留的构图、人物特征、文字、品牌标识、关键造型及用户满意之处。用户明确的夸张、梦境、拼贴、不规则透视或其他有意风格化属于保护条件，不能自行“纠正”。若设计意图与用途存在冲突，解释具体取舍供用户选择。

## 按证据选择检查重点

仅检查适用的维度；以下是观察方向，不是默认缺陷清单。混合风格按区域检查，并关注区域交界是否符合意图。

| 内容或风格线索 | 可检查的重点 |
| --- | --- |
| 人物插画、绘本 | 线条、笔触、色块、边缘与细节密度的关系；局部结构是否影响动作或叙事理解，避免用写实比例纠正夸张 |
| 摄影感 | 光源与阴影、接触和遮挡关系、材质反射、景深及局部结构；考虑多光源、镜头和后期效果等解释 |
| 像素画 | 网格与像素大小、调色板、边缘节奏、非预期模糊或抗锯齿；区分有意的混合分辨率与显示缩放造成的假象 |
| 海报、平面设计 | 文字可读性及与用户原文的一致性、排版层级、对齐与图形结构；无法辨认的字标为待核查，不猜写正确文案 |
| 建筑、室内 | 透视、重复结构、材质方向、空间与接触关系；保留用户有意的不可能空间 |

不默认去油光、降饱和度、加颗粒、锐化或增加细节。仅在具体区域存在可见现象且与用户目标相关时建议这些操作。没有足够证据时可以没有修改建议。

## 给出可选择的诊断

优先列 3–5 项最值得处理的建议；不足时少列，不为凑数制造问题。每项编号，并尽量在一段中包含：

- **位置与现象**：主体、区域、相邻参照物；需要坐标时注明所用图像尺寸及坐标基准，不编造精确测量。
- **判断与影响**：区分“可确认的问题”“可能不协调”“审美选项”，说明与用途或画面整体的关系。可确认的问题须有可核对依据；主观感受不能包装成事实。
- **调整与保护**：给出局部、可执行的方式和要保护的内容；必要时列保守方案与更明显的可选变化，不把变化等同于质量提高。
- **不确定性与决策**：说明遮挡、低分辨率、显示缩放或意图未知等限制；使用“可能”“建议核查”，指出是否需用户补充信息或选择。

默认到此停止编辑，让用户按编号选择。已有明确直接修改指令时，该指令在所述范围内即为授权，不重复确认每步；不得扩展为其他审美改动。

## 授权后的修整

1. 确认实际可用的工具及其能力、输入要求和权限，不假设有模型、蒙版、图层、精确像素处理或本地导出接口。使用适用且可用的编辑工具或 Skill，并遵守其操作要求。
2. 根据目标和控制需求选择可控图像处理、局部编辑或人工操作说明。对文字、标识和严格保留区域优先考虑能精确保护的方式；若工具不支持可靠局部控制，说明影响，在授权范围内选择可行方案或交由用户手工操作。
3. 将用户选中的建议对应到具体编辑：记录建议编号、目标区域、预期可观察变化和保护内容。条件性建议先核查条件，不把整份诊断都当成必须执行的清单。生成式编辑前简短说明细节可能变化，不承诺构图、身份特征、文字或标识绝对不变；不可声称工具实际不支持的区域锁定能力。
4. 默认保存为新文件或确认可用的新图层。写入前检查目标是否已存在，选用未占用的版本名称，如 `<原名>-afterframe-v01`；不能覆盖已有版本或原图，除非用户明确要求覆盖相应目标。只有真实支持图层的工具才能宣称创建了新图层。
5. 实际查看原图与编辑结果，逐条核对已执行建议：预期变化是否发生、是否更符合用户目标、保护内容是否偏移、是否引入新问题。分别标为“已改善”“部分改善”“未改善”或“无法确认”，并给出画面证据；审美取舍仍需用户判断，生成出新图本身不能证明建议正确。区分建议不合适与工具没有执行好，不用一次失败断言原诊断错误。无法回读结果则明确未完成视觉复核。
6. 未达到目标或出现副作用时，不默认交付为成功。若有具体可纠正原因且仍在授权范围内，可针对该原因修正；保留原图和各版本，比较后允许回退到原图或较早版本。没有明确改进方向、工具缺乏所需控制能力或连续修正无改善时停止，说明限制，不无限重生成，也不扩大修改范围。
7. 交付原图与结果的可查看对照、实际结果链接或真实保存位置，以及逐条建议的复核结论、未完成项和需用户判断的取舍。工具只返回会话图像时如实提供，不编造本地路径。

没有图像编辑工具或编辑失败时，明确说“尚未修改图片”，仍按选定区域提供可执行步骤、保护范围与验收要点；必要时提供供用户使用的编辑提示词，标明它是方案而非成品。不能把建议、工具调用尝试或预览描述当作已完成修改。

## 能力边界

不判断图片是否由 AI 生成，不提供“AI 感百分比”，不承诺绕过检测，不处理去水印或来源伪装。若请求包含这些内容，简短说明边界，并可继续处理用户授权的视觉质量问题。不要因图片有水印就拒绝无关的诊断或修整。
