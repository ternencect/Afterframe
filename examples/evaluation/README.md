# 合成示例素材

保留闭环示例使用的三张原图及[生成提示](generation-prompts.json)。这些是刻意设置局部问题的合成素材，不是用户作品；生成提示不等于缺陷真值，判断应以实际图片为依据。像素案例是视觉稿，未经生产精灵网格验证。

- [人物插画](inputs/illustration.png)：右袖密集排线，保留夸张比例与拼贴风格。
- [像素机器人](inputs/pixel.png)：右鞋模糊，保留大头、不对称天线与配色。
- [展览海报](inputs/poster.png)：标题错拼与底部文字低对比，保留几何图形及叠色。

目录沿用原位置，以保持历史调用记录、校验值及对照链接可追溯。第一轮诊断实验的其他材料已移出精简版仓库；本目录不再提供该轮完整实验。

查看[闭环示例与验证记录](../closed-loop/README.md)。
